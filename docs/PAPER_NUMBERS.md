## fold-0 诊断（§1、§5）

- 基线真实 big 的去向（行归一化 %）：water 0.1 / cake 0.3 / small 1.5 / medium 16.7 /
  big 65.8 / vast 15.5；PGSG：0.1 / 0.3 / 0.2 / 16.4 / 68.7 / 14.3。
  真实 medium（基线）：8.2 / 10.2 / 38.1 / 40.4 / 0.7 / 2.5。来源 `tools.figures.fig5_confusion`。
- fold-0 验证集只有 2 景含 big：`20231119T140527`（28.2 Mpx，IoU 0.061 → 0.142）与
  `20240129T115017`（49.4 Mpx，0.999 → 0.998），big 的增益几乎全部来自前者。
  来源 `tools.analysis.scene_cm --rank`。
- 辐射扰动（83 景全量，只改 HH/HV 有效像元并重算极化通道）：无扰动 macro mIoU 0.5031、
  hard-ice 0.2243；+0.30 z 时 hard-ice −0.039，−0.30 z 时 −0.054；±0.15 z 基本无影响。
  同一基线两个种子间 hard-ice 差 0.005。原始日志 `docs/logs/paper_radio_f0.log`、
  `paper_radio_pgsg4_f0.log`；z 与 dB 的换算见论文 §1 脚注（HH 0.30 z ≈ 2.5 dB）。
- 定性图两景：`20240607T200401` 窗口一致率 0.700 → 0.808（成功）；
  `20231119T140527` 0.093 → 0.170（失效模式，必须按失效展示）。来源 `tools.figures.fig7_qualitative`。
